# What to do with the time you have left

The hackathon runs 24 hours from 10:00 AM on 19 September. The core code already works, so your time goes into **understanding it, making it yours, testing it, and presenting it**.

## If you have 8 hours or more

| Block | Do this |
|---|---|
| Hour 1 | Follow docs/HOW_TO_RUN.md steps 1 to 5. Get it running. Click every button. Push to GitHub (step 11). |
| Hours 2 to 3 | **Read the code** so you can explain it: `backend/risk_engine.py` first, then `service.py`, then `simulator.py`. Change something small (a threshold, a node name, a colour) and commit it. |
| Hour 4 | Set up the phone alerts (Twilio, step 8) and Telegram (step 9). Test on your own phone. |
| Hour 5 | Test the camera page (step 6). Try candle, phone video, and yourself for person detection. |
| Hour 6 | Take 3 screenshots. Fix the README with your team names. Read docs/JUDGE_QA.md. |
| Hour 7 | Record the 2-minute demo video (docs/DEMO_SCRIPT.md). Optional: deploy for a live link. |
| Last 2 hours | Final test, final commit, submit. **Do not wait for the last minute.** |

## If you have 2 hours

1. Run it and push to GitHub (30 min).
2. Add your names and 2 screenshots to the README (15 min).
3. Record the demo video (20 min).
4. Paste the text from docs/SUBMISSION.md and submit (15 min).
5. Spend the rest reading `risk_engine.py` and docs/JUDGE_QA.md.

## Rules and honesty (important)

The rules say the project must be original, created by you or your team, and built during the hackathon.

* Make your **own real commits** during the time you work. Never fake the history.
* Read and understand the code. You will be asked about it.
* If you used AI tools to help, say so honestly if the organisers ask or if the rules require disclosure. Check the hackathon rules and ask the organisers if unsure.
* Customise it: your region, your node names, your team story, your own additions.
* Do not present simulated sensors as real hardware. Our README and pitch are honest about it, and that honesty helps your credibility.
